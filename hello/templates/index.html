Query Parameters

  • url is required for measurement and should point to a public image.
  • reference_size_mm=width,height sets the reference object size in one value.
  • reference_width_mm and reference_height_mm can be used together instead.
  • scale passes the same scale value used by ObjectMeasurer.
  • debug=1 includes structured diagnostic metadata without raw image bytes.
  • debug_images=1 includes structured debug data plus base64 PNG debug images.

Debug Images Example

The debug-image response is designed for browser clients and inspection tools. Render the image data with data:image/png;base64,<data>. 

{
  "width": 12.3,
  "height": 45.6,
  "measurements": [
    {
      "width": 12.3,
      "height": 45.6,
      "bbox": [10, 20, 120, 80]
    }
  ],
  "debug_images": {
    "imgWarp": {
      "mime_type": "image/png",
      "encoding": "base64",
      "data": "iVBORw0KGgo...",
      "width": 640,
      "height": 480,
      "shape": [480, 640, 3],
      "dtype": "uint8"
    }
  }
}
